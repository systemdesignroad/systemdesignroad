# Design a shopping cart with discounts

Item offers that compete, cart offers that stack in order, savings split across lines to the paisa so returns refund exactly, sales that end on their own, and the last pair of jeans.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/shopping-cart/read/](https://systemdesignroad.in/lld/shopping-cart/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/shopping-cart/](https://systemdesignroad.in/lld/shopping-cart/)

Level: Medium · Topics: Strategy, Decorator, Money, Concurrency

## Run it

Java 21 or newer:

```
javac *.java && java Main
```

`Main.java` reproduces every output quoted in the walkthrough.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
