# Design a vending machine

Coins and notes, change from what's really inside, cancels, jams and a service key, modelled with the State pattern.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/vending-machine/read/](https://systemdesignroad.in/lld/vending-machine/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/vending-machine/](https://systemdesignroad.in/lld/vending-machine/)

Level: Medium · Topics: State, Strategy, Money, Concurrency

## Run it

Java 21 or newer:

```
javac Design.java
```

The design compiles on its own; the walkthrough shows it running, step by step.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
