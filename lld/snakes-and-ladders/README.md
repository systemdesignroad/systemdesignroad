# Design snakes and ladders

Almost no rules, so the design carries everything: one class for snakes and ladders, boards that can't be broken, house rules, and millions of simulated games.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/snakes-and-ladders/read/](https://systemdesignroad.in/lld/snakes-and-ladders/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/snakes-and-ladders/](https://systemdesignroad.in/lld/snakes-and-ladders/)

Level: Easy · Topics: Validation, Strategy, Testing, Simulation

## Run it

Java 21 or newer:

```
javac Design.java && java Demo
```

`Demo` runs a short game or scenario from the walkthrough.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
