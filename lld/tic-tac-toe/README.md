# Design tic-tac-toe

The warm-up that still sinks people. Board, turns, a fast win check, undo, bots, and two clicks arriving at once.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/tic-tac-toe/read/](https://systemdesignroad.in/lld/tic-tac-toe/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/tic-tac-toe/](https://systemdesignroad.in/lld/tic-tac-toe/)

Level: Easy · Topics: Strategy, Observer, Undo, Concurrency

## Run it

Java 21 or newer:

```
javac Design.java && java Demo
```

`Demo` runs a short game or scenario from the walkthrough.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
