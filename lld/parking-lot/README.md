# Design a parking lot

The classic first LLD problem. Floors, spot sizes, gates, pricing and payments, and two races to get right.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/parking-lot/read/](https://systemdesignroad.in/lld/parking-lot/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/parking-lot/](https://systemdesignroad.in/lld/parking-lot/)

Level: Easy · Topics: Entities, Strategy, Observer, Concurrency

## Run it

Java 21 or newer:

```
javac Design.java
```

The design compiles on its own; the walkthrough shows it running, step by step.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
