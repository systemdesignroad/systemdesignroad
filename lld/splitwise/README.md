# Design Splitwise

Shared expenses: four kinds of split, money exact to the paisa, balances that always add to zero, simplifying debts, and phones that retry.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/splitwise/read/](https://systemdesignroad.in/lld/splitwise/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/splitwise/](https://systemdesignroad.in/lld/splitwise/)

Level: Medium · Topics: Money, Sealed types, Algorithms, Idempotency

## Run it

Java 21 or newer:

```
javac Design.java && java Demo
```

`Demo` runs a short game or scenario from the walkthrough.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
