# Design an elevator system

Several lifts, many floors: which car answers a call, which stop a car serves next, and buttons pressed from everywhere at once.

**Read the full walkthrough:** [https://systemdesignroad.in/lld/elevator/read/](https://systemdesignroad.in/lld/elevator/read/)
**Practise it stage by stage:** [https://systemdesignroad.in/lld/elevator/](https://systemdesignroad.in/lld/elevator/)

Level: Hard · Topics: Scheduling, Strategy, Simulation, Concurrency

## Run it

Java 21 or newer:

```
javac Design.java
```

The design compiles on its own; the walkthrough shows it running, step by step.

The walkthrough explains how to get here: the requirements, the entities, three versions of the class diagram, the patterns, the flows, the concurrency bug this design avoids (with a test), and the follow-up questions.
